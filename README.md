# LikeLionBar

멋쟁이사자처럼 부트캠프 출결을 까먹지 않게 해주는 macOS 메뉴바 앱.

> 개인이 만든 **비공식** 도구입니다. 멋쟁이사자처럼과 무관합니다.

## 이게 왜 필요한가

부트캠프 출결은 하루에 네 번 손이 갑니다.

| 시점 | 할 일 | 놓치면 |
|---|---|---|
| 아침 | QR 입실 (고용24 인증) | 지각. 3번이면 불참 |
| 아침 | 강의실 입장 (휴대폰 인증) | 출석 미인정 |
| 수업 중 | 카메라 켜두기 | 감점 |
| 저녁 | QR 퇴실 | 그날 출석이 통째로 날아감 |

자리에 앉아 있는데 절차를 까먹어서 손해 보는 게 문제입니다. 알림은 한 번 넘기면 끝이지만,
**메뉴바에서 지각까지 남은 시간이 줄어드는 건 무시하기 어렵습니다.**

## 메뉴바가 보여주는 것

| 상황 | 표시 |
|---|---|
| 08:40 이전 / 주말 / 쉬는 날 | 아이콘만 (조용) |
| 입실 전, 마감까지 시간 있음 | 🔴 `23:00` 카운트다운 |
| 입실 전, 5분 미만 | 🔴 `04:32` **깜빡임** |
| 마감 넘김 | 🔴 `지각` |
| 입실 후, 강의실 미입장 | 🟡 `강의실` |
| 17:57 이후, 퇴실 전 | 🟠 `퇴실` |
| 다 끝냄 | ✅ |

메뉴를 열면 오늘의 4단계 체크리스트가 있고, 처리한 뒤 클릭해 완료로 표시합니다.
`강의보드 열기`를 누르면 로그인된 Chrome 프로필로 해당 페이지가 열립니다.

## 하지 않는 일

**고용24 인증과 휴대폰 인증을 대신하거나 우회하지 않습니다.** 그 절차는 실제로 그 자리에
있는지 확인하려고 존재하고, 국비 지원 훈련과정의 출결이라 우회는 부정훈련 문제가 됩니다.
이 앱은 "언제 뭘 해야 하는지"를 놓치지 않게 해줄 뿐, 출석은 본인이 합니다.

## 시스템 요구사항

- **macOS 14 (Sonoma) 이상**
- Apple Silicon · Intel 맥 모두 지원 (유니버설 바이너리)
- Chrome — 부트캠프 로그인 세션이 있는 브라우저
- **Windows·Linux에서는 실행되지 않습니다.** 메뉴바·알림이 macOS 전용
  프레임워크라 이식할 수 있는 코드가 아닙니다.

## 설치

1. [Releases](../../releases)에서 `LikeLionBar.zip`을 받아 압축을 풀고
   **`/응용 프로그램`으로 옮깁니다**
   (로그인 시 자동 시작이 이 위치에서만 안정적으로 등록됩니다)
2. 실행하면 메뉴바에 아이콘이 생깁니다
3. 알림 권한을 허용합니다
4. 메뉴 → `설정…`에서 **과정 주소**와 **Chrome 프로필**을 자기 것으로 맞춥니다
5. `로그인 시 자동 시작`을 켭니다

### 과정 주소 찾기

강의보드 URL이 `bootcamp.likelion.net/my/courses/detail/`**`kdt-cld-6th`**`/board` 라면
굵은 부분이 과정 주소입니다.

### Chrome 프로필 찾기

부트캠프에 로그인된 Chrome 창에서 `chrome://version` 을 열고 `프로필 경로`의 마지막 폴더명
(`Default`, `Profile 1` 등)을 넣습니다. 비워두면 Chrome 기본 프로필을 씁니다.

> Chrome이 이미 실행 중이면 프로필 지정이 무시될 수 있습니다. 그럴 땐 해당 프로필 창을
> 띄워둔 상태로 쓰세요.

## 설정

모든 시각을 바꿀 수 있습니다. 기수·과정마다 시간표가 다르므로 기본값은 참고용입니다.

- **카운트다운 시작** — 이 시각부터 메뉴바에 남은 시간이 뜹니다
- **지각 마감** — 카운트다운의 목표점
- **강의실 버튼 활성화** — `강의실 입장` 버튼이 실제로 눌리기 시작하는 시각
- **입실/퇴실 알림** — 쉼표로 여러 개. 마지막 입실 알림은 최종 경고로 다뤄집니다
- **카메라 확인 간격** — `0`이면 끕니다

쉬는시간이 불규칙해서 카메라는 "쉬는시간 끝"에 맞출 수 없습니다. 대신 일정 간격으로 알리고
알림에서 `30분 뒤에`로 미룰 수 있습니다.

## 문제가 생기면

메뉴 → `기록 폴더 열기` 안의 `debug.log`에 상황이 남습니다.

- `state.json` — 오늘 진행 상황
- `log.jsonl` — 전체 이력

## 개발

Xcode 없이 Command Line Tools만으로 빌드됩니다.

```bash
swift run CoreChecks          # 검사 (XCTest 없이 도는 자체 하네스)
./scripts/bundle.sh           # .app 조립 + ad-hoc 서명
./scripts/preview.sh 09:04:30 # 임의 시각의 메뉴바 상태를 즉시 확인
```

`preview.sh`는 다음날 아침을 기다리지 않고 상태 전이를 보기 위한 도구입니다.
실제 출결 기록을 건드리지 않고 임시 폴더에 따로 씁니다.

```bash
./scripts/preview.sh 08:47:00                    # 카운트다운
./scripts/preview.sh 09:04:30                    # 30초 뒤 깜빡임 전환
./scripts/preview.sh 09:11:00                    # 지각
./scripts/preview.sh 09:30:00 checkIn            # 강의실 조르기
./scripts/preview.sh 17:58:00 checkIn,classroom  # 퇴실
```

### 배포
