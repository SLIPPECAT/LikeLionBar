# LikeLionBar

부트캠프 출결을 까먹지 않게 해주는 macOS 메뉴바 앱입니다.

> 부트캠프를 들으면서 제가 쓰려고 만든 **비공식** 도구예요. 멋쟁이사자처럼과는 관계없습니다.

![알림](docs/notification.png)

---

## 왜 만들었나

부트캠프를 듣다 보니 출결에 손이 하루에도 여러 번 갑니다.

| 시점 | 할 일 | 놓치면 |
|---|---|---|
| 아침 | QR 입실 (고용24 인증) | **지각. 3번이면 불참** |
| 아침 | 강의실 입장 (휴대폰 인증) | 출석 미인정 |
| 매시간 | 정각~20분 사이 카메라 켜두기 | 그 시간 미인정 |
| 저녁 | QR 퇴실 | **그날 출석이 통째로 날아감** |

자리에는 앉아 있는데 절차를 깜빡해서 출석이 안 잡히는 경우가 있더라고요. 수업은 다 들었는데 퇴실 버튼 하나 때문에 하루가 인정 안 되면 아쉽잖아요.

알림 앱도 써봤는데, 배너는 한 번 넘기면 그걸로 끝이더라고요. 그런데 **메뉴바에서 지각까지 남은 시간이 초 단위로 줄어드는 건 이상하게 무시가 안 됩니다.** 이 앱은 그 점에 기대고 있습니다.

## 설치

**macOS 14 (Sonoma) 이상**에서 동작하고, Apple Silicon과 Intel 맥 모두 지원합니다.
윈도우나 리눅스에서는 실행되지 않아요. 메뉴바와 알림이 macOS 전용 기능이라 이식할 수 있는 코드가 아닙니다.

1. [Releases](../../releases)에서 `LikeLionBar.zip`을 받아 압축을 풉니다
2. **`/응용 프로그램`으로 옮겨주세요.** 로그인 시 자동 시작이 이 위치에서만 안정적으로 등록됩니다
3. 실행하면 메뉴바에 사자가 생깁니다. 알림 권한을 허용해주세요
4. 메뉴 → `설정…`에서 **과정 주소**와 **Chrome 프로필**을 본인 것으로 바꿉니다
5. 맨 아래 **`로그인 시 자동 시작`을 켜고 `저장`** — 이걸 안 켜면 매일 직접 실행해야 합니다

Apple 공증(notarization)을 받아서 "확인되지 않은 개발자" 경고 없이 열립니다.

## 설정

![설정](docs/settings.png)

기수랑 과정마다 시간표가 다르기 때문에 **모든 시각을 바꿀 수 있게** 만들었습니다. 기본값은 제 과정 기준이라 참고만 해주세요.

### 과정 주소 찾기

강의보드 URL이 `bootcamp.likelion.net/my/courses/detail/`**`kdt-cld-6th`**`/board` 라면 굵은 부분이 과정 주소입니다.

### Chrome 프로필 찾기

부트캠프에 로그인된 Chrome 창에서 `chrome://version`을 열고 `프로필 경로`의 마지막 폴더명(`Default`, `Profile 1` 등)을 넣어주세요. 비워두면 기본 프로필을 씁니다.

> Chrome이 이미 실행 중이면 프로필 지정이 무시될 수 있습니다. 그럴 땐 해당 프로필 창을 띄워둔 상태로 쓰시면 됩니다.

### 주요 항목

| 항목 | 뜻 |
|---|---|
| 카운트다운 시작 | 이 시각부터 메뉴바에 남은 시간이 뜹니다 |
| 지각 마감 | 카운트다운이 향하는 목표점 |
| 강의실 버튼 활성화 | `강의실 입장` 버튼이 실제로 눌리기 시작하는 시각 |
| 입실·강의실·퇴실 알림 | 쉼표로 여러 개를 넣습니다. 마지막 입실 알림은 최종 경고로 다뤄집니다 |
| 알림에 소리 사용 | **기본은 꺼짐입니다.** 끄면 배너만 뜹니다 |
| 카메라 마감·알림 | 정각 기준 분입니다. 마감을 `0`으로 두면 이 기능을 끕니다 |
| 공휴일에 자동으로 쉬기 | 공휴일 목록을 받아와 쉬는 날로 처리합니다 |

## 내 알림

병원이나 외출 같은 개인 일정도 넣을 수 있습니다. 설정 맨 아래 **`내 알림`** 에서 추가해주세요.

```
13:40   병원              ☐ 매 평일   ⊖
15:10   나가야 함          ☑ 매 평일   ⊖
        [ 알림 추가 ]
```

- **`매 평일`을 끄면** 오늘 하루만 울리고 다음 날 목록에서 알아서 사라집니다
- **켜면** 평일마다 반복됩니다
- 메뉴를 열면 오늘 울릴 목록이 보이고, 이미 지난 건 흐리게 표시됩니다

일회성 알림은 **쉬는 날로 표시해도 울립니다.** 병원 예약을 쉬는 날이라고 거르면 곤란하니까요. 반대로 매 평일 반복은 쉬는 날에 쉽니다.

## 공휴일 처리

공휴일이면 자동으로 쉬는 날로 바꿔줍니다. 다만 이건 **확정이 아니라 제안**이에요. 부트캠프가 공휴일에 수업하는 경우도 있고, 반대로 공휴일이 아닌 자체 휴일도 있으니까요.

그래서 메뉴에 `설날 — 공휴일이라 쉬는 날 처리됨`처럼 사유가 뜨고, 직접 해제할 수 있습니다. 한 번 해제하면 그날은 다시 켜지지 않습니다.

공휴일 목록은 인터넷에서 받아와 연도별로 저장해둡니다. 나가는 정보는 연도와 국가 코드뿐이고, 네트워크가 없으면 저장해둔 걸 쓰고 그것도 없으면 공휴일 판단만 건너뜁니다. 설정에서 끄면 요청 자체를 안 합니다.

## 하지 않는 일

**고용24 인증과 휴대폰 인증을 대신하거나 우회하지 않습니다.**

그 절차는 실제로 그 자리에 있는지 확인하려고 있는 거고, 국비 지원 훈련과정 출결이라 우회하면 부정훈련 문제가 됩니다. 이 앱은 "언제 뭘 해야 하는지"를 놓치지 않게 해줄 뿐이고, 출석은 본인이 하는 겁니다.

## 문제가 생기면

메뉴 → **`기록 폴더 열기`** 안의 파일을 보면 무슨 일이 있었는지 알 수 있습니다.

| 파일 | 내용 |
|---|---|
| `debug.log` | 실행·알림·설정 변경 기록 (512KB 넘으면 회전) |
| `state.json` | 오늘 진행 상황 |
| `log.jsonl` | 전체 이력 |

**알림이 안 뜬다면** `시스템 설정 → 알림 → LikeLionBar`에서 허용됐는지 봐주세요. 배너를 자주 놓친다면 알림 스타일을 `배너` 대신 **`알림`** 으로 바꾸면 직접 닫을 때까지 남아 있습니다.

**로그인 시 자동 시작이 실패하면** 앱이 `/응용 프로그램`에 있는지 확인해주세요. 임시 폴더나 다운로드 폴더에서는 등록이 거부됩니다.

## 개발

Xcode 없이 **Command Line Tools만으로** 빌드하고 서명하고 공증까지 됩니다.

```bash
swift run CoreChecks          # 검사
./scripts/bundle.sh           # .app 조립 + ad-hoc 서명
./scripts/bundle.sh release   # 유니버설 바이너리 (arm64 + x86_64)
```

검사는 XCTest 대신 직접 만든 하네스로 돌립니다. Command Line Tools에는 XCTest도 swift-testing 런타임도 없더라고요. 어차피 검증할 게 순수한 값 비교라 프레임워크 없이도 충분했습니다.

### 미리보기

출결 앱을 만들 때 제일 곤란했던 게, 아침 상태를 확인하려면 다음 날 아침까지 기다려야 한다는 점이었습니다. 그래서 아무 시각이나 주입해서 볼 수 있게 만들었어요. 실제 출결 기록은 건드리지 않고 임시 폴더에 따로 씁니다.

```bash
./scripts/preview.sh 08:47:00                     # 입실 카운트다운
./scripts/preview.sh 09:04:30                     # 30초 뒤 깜빡임 전환
./scripts/preview.sh 09:11:00                     # 지각
./scripts/preview.sh 09:30:00 checkIn             # 강의실 안내
./scripts/preview.sh 17:58:00 checkIn,classroom   # 퇴실
./scripts/preview.sh 08:46:30 "" 30               # 30배속 (아침 21분 → 45초)
```

| 환경 변수 | 용도 |
|---|---|
| `LIKELIONBAR_FAKE_TIME` | 시작 시각 (`2026-07-28T08:47:00`) |
| `LIKELIONBAR_FAKE_SPEED` | 배속. 알림 시퀀스를 압축해서 볼 때 |
| `LIKELIONBAR_FAKE_DONE` | 완료 단계 (`checkIn,classroom`) |
| `LIKELIONBAR_FAKE_PHOTOS` | 카메라 확인을 마친 시간대 (`9,10,11,13`) |
| `LIKELIONBAR_TRACE` | 매 틱의 판단 근거를 로그에 남김 |
| `LIKELIONBAR_OPEN_SETTINGS` | 실행하자마자 설정 창 열기 |

### 배포

```bash
./scripts/make-icon.sh lion.png   # 1024x1024 PNG → AppIcon.icns
./scripts/bundle.sh release
./scripts/sign.sh                 # Developer ID 서명
./scripts/notarize.sh             # 공증 + 티켓 첨부
```

### 구조

로직과 화면을 나눠뒀습니다. 시각을 인자로 받게 만들어야 테스트가 가능해서요.

```
Sources/
├── LikeLionBarCore/    순수 로직. AppKit에 의존하지 않아 시각을 주입해 검증한다
│   ├── ScheduleEngine    시각·상태 → 메뉴바 표시
│   ├── ReminderEngine    두 틱 사이에 지나간 알림 찾기
│   ├── StateStore        영속화·날짜 롤오버·이력
│   ├── CustomReminder    사용자 등록 알림
│   └── Holiday           공휴일 캐시
├── LikeLionBar/        AppKit UI
└── CoreChecks/         검사 하네스
```
